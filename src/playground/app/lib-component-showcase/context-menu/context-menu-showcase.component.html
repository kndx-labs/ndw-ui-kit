Context menu (right-click)

Two right-click targets below demonstrate the two ways to wire a controller factory to ndwuPopoverTrigger. Both open the same menu.

Approach 1 — [popoverControllerFactory] input
The factory is passed directly as a template binding. Preferred for direct template usage.

Right-click here (input-based factory)

Approach 2 — NDWU_POPOVER_CONTROLLER_FACTORY DI token
The factory is provided in component providers and injected automatically. Required for hostDirectives wrappers (e.g. ndwuTooltip).

Right-click here (DI token factory)
