With Content Padding

[ndwuScrollbarContentPadding] adds inner breathing room to the scroll box itself, distinct from the track gutter above. Top/left padding scrolls away with the content; bottom/right padding adds trailing space. It composes with the reserved track gutter, so content still never renders under the scrollbar.

Uses CSS custom properties internally — can also be set via stylesheet.

Disabled scrollbar — container grows instead of scrolling

[ndwuScrollbarDisabled] turns the custom scroll box into a pass-through wrapper: both axes grow, both tracks disappear, and the reserved gutter is released. Nothing inside is destroyed by the toggle, so component and DOM state survive — type into the field below, then toggle.

The call site still owns its own height cap. Here scrollbar-grow-demo--grow drops height; without that, the container would stay capped even with the scrollbar disabled.
